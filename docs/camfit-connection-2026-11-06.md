# 캠핏 연결 흐름 구현 · 0.1.16

2026-11-06. Q72·Q73과 ‘다음 작업 이어서 진행’ 요청에 따라 로그인과 파일 수신을 한 작업으로 연결했다. **모의 화면과 가상 XLSX 검증까지 완료했으며 실제 캠핏·Windows 검증은 남아 있다.**

## 바뀐 동작

이전에는 설정의 로그인 버튼이 창만 열어, 별도로 동기화를 시작하지 않고 내려받은 파일은 앱에 반영되지 않았다. 이제 **설정 → 캠핏 연결**을 누르면 창의 첫 페이지가 열리기 전부터 파일을 받을 준비를 한다. 기존 연결 설정이 있으면 버튼 이름은 **캠핏 동기화**다.

로그인 후 구별 가능한 예약 메뉴와 내보내기 버튼을 찾아 XLSX를 받는다. 처음 받은 파일은 열·상품·예약 상태와 미리보기를 확인한 뒤 **연결하고 동기화**를 누른다. 같은 형식의 다음 파일부터는 자동 반영한다. 세션이 만료되면 로그인 안내를 보이고, 인증된 화면을 확인한 뒤 저장된 예약 경로로 한 번 복귀한다. 다운로드 클릭 뒤 화면이 바뀌어 실행 결과를 받지 못해도 같은 작업에서 버튼을 다시 누르지 않는다.

로그인·예약 목록 이동·파일 수신·검사·저장 단계를 표시한다. 실패하면 오류를 유지하고 **다시 연결**, 진행 중에는 **동기화 중단**을 제공한다. 수신·검사·저장이 모두 끝나야 완료를 표시한다.

## 자동 조작의 범위

실제 캠핏 로그인 뒤 화면을 확보한 상태가 아니므로 특정 예약 URL·API를 만들어 호출하지 않는다. `electron/camfit-page.cjs`는 공식 도메인의 화면 요소를 다음 조건으로 판별한다.

- 첫 연결의 예약 목록은 표시된 표 제목에 `예약번호`와 `입실일`·`체크인`·`예약자`·`예약자 이름` 중 하나가 함께 있어야 한다.
- 예약 목록 이동은 같은 도메인의 `예약 목록`·`예약 내역`·`예약 관리`에 해당하는 유일한 링크만 사용한다. ‘전체’ 접두사를 허용하고 최대 두 단계까지만 이동한다.
- 첫 자동 내보내기는 위 예약 목록에서 허용된 이름의 버튼·링크가 하나일 때만 누른다. 연결 이후에는 저장한 경로와 버튼 이름이 일치해야 한다. 보이지 않거나 비활성화된 요소는 제외한다.
- 로그인 입력 화면이 보이면 내보내지 않는다. 저장 경로 복귀는 예약 목록이나 로그아웃 컨트롤로 인증된 화면을 확인한 뒤 수행한다. 비밀번호 입력값·쿠키·인증 토큰은 읽지 않는다.
- 메뉴·버튼을 구별하지 못하거나 중복되면 직접 예약 목록을 열거나 내보내기를 누르도록 안내한다. 기존 CSV·XLSX 수동 내보내기 수신과 명단 가져오기도 유지한다.

**업체·조회 기간·상태 필터는 자동 선택·변경하지 않는다.** 저장한 화면을 다시 열었을 때 캠핏이 정한 현재 조회 조건에 포함되는 예약만 받는다. URL 쿼리를 복사하지 않는 기존 정책을 유지한다. 업체·날짜 쿼리, 추가 내보내기 팝업, 사유 입력 등이 필수라면 실제 화면을 확인해 추가 연결해야 한다.

## 기존 자료 보존

이번 변경은 캠핏 연결 시작과 화면 탐색·진행 안내에 한정한다. 예약번호·단위번호 중복 검사, 취소·날짜 변경 확인 대기, 기존 배정·현장 기록 유지, 목록에서 사라진 예약을 삭제하지 않는 규칙을 유지한다. 내려받기나 검사에 실패하면 예약과 마지막 성공 시각을 갱신하지 않는다.

0.1.15의 저장된 140자리·15시설 배치와 기존 PC의 명시 적용 기능을 그대로 포함한다. 운영 데이터·PIN·캠핏 세션을 읽거나 변경하지 않고 테스트 전용 임시 폴더만 사용했다.

## 남은 확인

이미 내려받은 캠핏 `.xlsx`의 익명화 사본으로 제목 행·날짜·상품·상태·여러 자리 식별을 확인해야 한다. 이름·연락처·메모는 지우거나 가상값으로 바꾸되 열 구조와 예약/단위번호의 관계는 유지한다. Windows에서 실제 로그인 후 메뉴·내보내기·업체·조회 범위·세션 만료 동작을 확인해 판별 규칙을 보완한다. 지금 로그인이나 비밀번호 전달을 다시 요청하지 않는다.

이 검증 전에는 ‘실제 캠핏에 로그인만 하면 모든 예약을 자동 수집한다’고 보장하지 않는다. 주기 수신·앱 종료 중 수신은 이번 구현에 포함하지 않았다. [최초 설계](camfit-auto-connect-2026-11-06.md), [사용 순서](camfit-sync-2026-10-06.md).
