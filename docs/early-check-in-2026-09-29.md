# 입실일 당일 조기 입실 허용

2026-09-29 · 버전 0.1.3

사용자가 오후 2시 이전에도 입실할 수 있도록 요청했다. 0.1.2의 14시 강제 제한을 해제하고, 기본 시각은 유지하면서 입실일 당일의 조기 입실을 허용했다.

- 현장에서 빈자리에 배정하는 경우와 이미 지정된 객실의 입실 처리에 동일하게 적용한다.
- 충돌 검사와 실제 배정 시작 시각은 입실 처리한 현재 시각을 사용한다. 예를 들어 오전 9시 입실이면 9시부터 퇴실 시각까지 다른 예약·장박·사용중지와 겹치는지 확인한다.
- 이전 손님이나 장박이 오전 11시까지 이용 중이면 오전 9시 입실은 차단하며, 해당 이용이 끝나는 11시부터 허용한다.
- 예약된 입실일 전날이나 퇴실 시각이 지난 예약에는 입실할 수 없다.
- 화면의 14:00 안내를 ‘기본 입실’로 명확히 표시하고 조기 입실 안내를 추가했다. 새 요금 규칙은 추가하지 않았다.

## 검증

- 운영 규칙·저장 테스트 35개 통과. 00:00·09:00·13:59:59 입실, 입실일 전날·퇴실 이후 차단, 오전 손님·장박·사용중지 충돌을 확인했다.
- 브라우저 테스트 19개 통과. 오전 직접 배정과 지정 객실 입실, 재실행 후 실제 입실 시각 보존을 확인했다.
- TypeScript 검사, 제품 빌드, 코드 형식 검사 통과.
- Mac Electron 22 / Chromium 108에서 기존 저장·복원 검사와 오전 9시 입실 후 디스크 저장을 확인했다.
- Windows x64·ia32 통합 설치 파일은 [0.1.3](../release/Sopung-Camp-Setup-0.1.3.exe)이다. [SHA-256](../release/Sopung-Camp-Setup-0.1.3.exe.sha256)을 함께 보관한다. Windows 실기기 설치·실행 검증은 아직 남아 있다.

기존 검토 기록의 14시 강제 제한 설명보다 이번 사용자 지시와 [요구사항 Q48](requirements.md)의 규칙이 우선한다.
