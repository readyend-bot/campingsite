## 2026-10-06 계단·개수대 옆 길 재정리

사용자가 긴 사다리 그림을 정리하고 라동 개수대 바로 옆으로 길을 올려 가로 구간을 넓히라고 지시했다(Q58·Q59). 추가 항공사진(Q60)으로 갈림과 상부 진입로를 대조했다. 0.1.8에서 표시 좌표만 수정하고 예약·장박·시설 등록은 유지한다. [추가 수정 기록](usability-update-2026-10-06.md).

## 2026-10-06 마동 위치 정정

사용자가 마동은 도로 건너 A동·라동과 나란히 놓인다고 직접 정정했다(Q55). 0.1.7에서는 마동 전체 표시와 연결 진입로를 위로 옮긴다. 이전에 사진으로 해석한 라동·다동 높이는 최신 지시로 대체한다. 마동 내부의 자리·시설 배치와 운영 자료는 유지한다. 라동 오른쪽의 갈림에서 왼쪽은 A·B동 오르막, 직진은 마동이다. 다6·7 ↔ 나22·23, 나4·5 ↔ 가10 오른쪽 계단도 확인했다. [정정 기록](layout-corrections-2026-10-06.md)을 따른다.

## 2026-10-05 전체 도식 위치 수정

사용자가 기존 전체 도식의 위치가 맞지 않는다고 지적했다. 0.1.6에서 두 도면을 주 진입로 기준으로 연결하고 사용자 항공사진·현장 안내판·공식 B동 배치 사진을 대조한 전체 평면도를 적용했다. 나동의 왼쪽 아래 꺾임, 짧은 가동, A동 윗줄 시작, 세로형 마동·시설·사이트 줄을 함께 표시한다. [구체적인 근거와 결과](overview-geometry-2026-10-05.md)를 따른다. 전체 표시 좌표만 변경하며 운영 자료의 자리·예약·장박은 보존한다.

## 2026-10-05 사용자 제공 자료로 갱신

사용자가 [하단 도면](reference/user-plan-2026-10-05-lower.png)과 [상단 도면](reference/user-plan-2026-10-05-upper.png)을 직접 제공하고, ‘장박’ 표시는 무시하여 가려진 번호를 연번으로 복원해 앱에 반영하라고 명시했다. 이 자료와 지시를 0.1.5의 기준으로 사용한다. **아래 2026-09-28 공개 자료 조사와 당시 미확정 결론은 과거 기록**이며, 최신 구현은 [도면 반영 기록](site-plan-2026-10-05.md)을 따른다.

가10·나27·다21·라23·마15·A26·B18로 총 140자리를 구성했다. 라1–11 글램핑과 라동 방갈로 A, B동 카라반 3–12·방갈로 B를 포함한다. B3·4·5·6·9·11·12 카라반은 럭셔리, 7은 골든, 8은 스페셜3, 10은 스파3다. 물리 A동과 방갈로 A, 오토 B1·B2와 카라반 호수를 구별한다.

시설은 가동 매점·트램펄린, 나·다동 개수대, 라동 화장실·개수대, 마동 탁구장·샤워실/화장실·개수대, A동 화장실·개수대, B동 화장실/개수대·분리수거장·수영장으로 총 14개 객체다. 장박·사용중지는 사진에서 등록하지 않고 사용자가 직접 등록한다. 숫자가 없는 추가 칸은 사이트로 만들지 않는다. 전체 구역은 가→나→다→라→A→B 순서, 마는 라 오른쪽 도로 건너편으로 표시한다. 실측 거리·항공사진 좌표는 아니다.

현재 예약은 캠핏만 받는다고 확인했다. 사용자에게 사업자 계정은 있으나 **로그인은 Windows 설치 후 직접 진행**한다. 공개 [캠지기센터 로그인 화면](https://admin.camfit.co.kr/)과 [공식 사업자 안내](https://biz.camfit.co.kr/)를 확인했지만 인증 후 예약 조회 화면·외부 제공 API·내보내기 규격은 확인하지 않았다. 0.1.8에는 별도 로그인 세션과 **CSV/XLSX 내보내기 기반 버튼 동기화**를 구현했다. 첫 파일에서 연결을 확인해야 하며 **실제 캠핏 인증·내보내기 기능은 미검증**이다. 사용자는 내보내기 존재도 아직 확인 전이라고 답했다(Q64). [연결 안내](camfit-sync-2026-10-06.md). 실제 계정으로 로그인하지 않았고 외부 문의도 발송하지 않았다.

## 동 구성과 상대 위치

현장 안내판에는 **가·나·다·라·마·A·B, 총 7개 동**이 표시되어 있다. 안내판 그림 기준 아래쪽 관리실·입구에서 위로 올라가면 가 → 나 → 다 → 라 → A → B 순서이고, 마동은 주 진입로 건너 위쪽 오른편의 별도 구역이다. B동에는 수영장과 카라반이 있다. 입구 옆 별도 부지는 안내판상 주차장이다.

여기서 위·아래·좌·우는 **사진과 종이 배치도에서 보이는 방향**이다. 지도상의 동서남북이나 실측 좌표로 해석하지 않는다.

## 종이 도면상의 번호 방향

실측 배치 좌표가 아니라 도식 제작을 위한 자료 판독이다. 가려진 번호의 복원은 사용자 확인이 필요하다.

- **가:** 매점 쪽 아래 줄은 오른쪽부터 1→5, 위 줄은 왼쪽부터 6→10. 2026년 도면에 10이 중복 표시된 듯한 추가 칸이 있고 2024년 도면에서는 추가 칸에 X가 있어 확정 자리로 세지 않았다.
- **나:** 가동 쪽 줄은 도로 쪽 1에서 시작해 왼쪽으로 진행하며 15까지 이어진다. 반대쪽 줄은 왼쪽 16에서 오른쪽 27까지. 개수대와 꺾인 통로로 중간 구간이 나뉜다.
- **다:** 나동 쪽 줄은 도로 쪽 1에서 왼쪽 11로 진행하고, 반대쪽 줄은 왼쪽 12에서 오른쪽 21로 진행한다. 오른쪽 끝에 개수대가 있다.
- **라:** 아래쪽 줄은 왼쪽부터 글램핑10→1, 그 오른쪽에는 23·22 및 장박 칸이 있다. 글램핑11은 왼쪽 꺾인 모서리, 라12는 그 위. 위 줄은 라13→19 뒤에 방갈로 A·화장실·개수대가 이어진다.
- **마:** 왼쪽 줄은 아래에서 위로 1→6, 위쪽에 7·8. 오른쪽 줄은 위에서 아래로 9→12, 가운데 줄은 아래에서 위로 13→15로 복원된다.
- **A:** 두 줄이라는 자료는 있으나 전체 번호와 각 위치를 확정할 도면이 없다.
- **B:** 카라반 배치도상 왼쪽에서 방갈로 B·12·11·10·9·8·7·6·5·4·3 순서다. 수영장 건너편과 입구 부근의 오토캠핑 자리 번호는 전체를 복원하지 못했다.

## 배정 프로그램에 영향을 주는 발견

### 온라인 예약번호와 현장 자리번호는 다르다

이전 조사에서는 캠핏 오토 상품의 `선착순01–80` 같은 번호와 과거 `선착순96` 사례가 발견되었다. 이것은 실제 동별 자리 번호와 일치하지 않는다. 온라인 판매 슬롯 개수로 현장 총수를 정하면 안 된다.

글램핑에도 `선착순01` 같은 이름이 반복되며, 표시명이 같은 오토 상품도 조사되었다. 상품 정보와 예약 식별자를 함께 확인해 가져와야 한다. **어느 예약을 실제 어느 자리에 배정할지는 별도 기록한다.**

근거: [캠핏 용인소풍캠핑장](https://camfit.co.kr/camp/605d6185d8f6c1001da54273), 이전 조사 보존본. 이번 인수 과정에서는 캠핏 웹 도구가 동적 상세 내용을 반환하지 않아 실시간 판매 슬롯 수를 재검증하지 않았다.

### 방갈로 A와 A동은 다르다

종이 도면에서 **방갈로 A는 라동**의 화장실·개수대 옆에 있다. 예약 상품의 `방갈로 A동`을 물리적인 A동으로 자동 해석하면 안 된다. 방갈로 B는 B동 카라반 줄 끝에 있다.

### 장박은 기간별 현황이다

2024년과 2026년 종이 도면은 장박으로 표시된 자리가 서로 다르다. 사진상의 장박 칸을 고정 속성으로 만들지 않는다. 사용자 Q7대로 시작·종료일을 가진 점유 기록으로 설계해야 한다. 현재 장박 초기 명단은 아직 받지 않았다.

### 내보내기 형식과 네이버 중복은 추가 확인이 필요하다

이전 조사는 캠핏의 일일 예약표와 전체 예약 내보내기가 서로 다르고, 일일 예약표의 날짜가 연도 없이 표현될 수 있다는 자료를 확보했다. 전체 예약 파일과 현재 네이버 파일의 실제 열 구성은 확정하지 못했다.

2026-09-28에 [캠핏 공식 사업자 안내](https://biz.camfit.co.kr/)에서 네이버 예약 연동 기능의 존재를 확인했다. 그러나 이 캠핑장에 연동이 설정되어 있는지, 실제 내려받은 파일에 같은 예약이 어떻게 담기는지는 확인하지 못했다. 사용자도 Q47에서 기존 연동 여부는 아직 모른다고 답했다. **이름·전화·입실일이 같다는 이유만으로 자동 병합하는 것은 확정된 규칙이 아니다.** 같은 손님의 여러 자리 예약을 구별해야 한다. 실제 샘플을 기준으로 중복 후보 확인과 식별 방식을 설계한다.

### 예약 자동 불러오기 추가 검토

- 홈페이지 시설 배치도는 주로 B동 카라반 배치를 설명한다. 이것만으로 전체 동별 오토 자리 수를 셀 수 없다.
