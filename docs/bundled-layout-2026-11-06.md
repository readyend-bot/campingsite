# 저장된 자리배치를 포함한 Windows 설치 파일

2026-11-06 · 0.1.15 · 사용자 결정 Q71

## 적용한 내용

현재 Mac 앱에 저장된 **7개 동·140자리·15시설**의 배치를 설치 파일에 포함했다. 신규 PC는 잠금 설정 후 이 배치를 자동으로 저장하고 표시한다. 종이 도면 기본값과 달랐던 **마7 `(24, 0.2)`·마8 `(50, 0)`**의 위치도 유지한다.

원본은 `/Users/bj/Library/Application Support/Sopung Camp/camp-data.json`이며 마지막 저장 시각은 `2026-10-06T09:42:55.908Z`다. 2026-11-06에 읽어 `src/bundledLayout.json`으로 추출했다. 원본의 자리·시설 필드와 설치 초기값을 대조해 자리 140개·시설 15개가 모두 일치함을 확인했다. 새 PC에서는 자리 ID만 공식 도면 ID로 정규화한다. 기존 PC의 자리 ID는 바꾸지 않는다.

추출본에는 자리 이름·동·유형·삭제 상태·동별 좌표·객실 세부 유형과 시설의 종류·좌표·크기·길목 위치만 들어 있다. 예약·배정·장박·변경 이력·잠금·캠핏 로그인 정보는 복사하지 않는다. 현재 원본에는 항공사진이나 사진 위 좌표가 없어 사진은 포함하지 않았다. 원본 운영 파일은 수정하지 않았다.

## 설치와 기존 PC 적용

1. `release/Sopung-Camp-Setup-0.1.15.exe`로 설치 또는 업데이트한다.
2. 새 PC라면 PIN 또는 비밀번호를 설정한 뒤 저장된 배치를 바로 확인한다.
3. 이미 앱을 설치했던 PC라면 **설정 → 저장된 자리배치 적용 → 확인**을 누른다. 기존에 빈 데이터를 저장한 경우에도 같은 메뉴를 사용한다.
4. 현재 자료를 먼저 백업하고 배치를 적용한다. 백업이 실패하면 기존 배치를 유지하며 오류를 표시한다.

기존 PC에 저장된 데이터는 설치·업데이트만으로 덮어쓰지 않는다. 적용을 선택하면 같은 자리의 동별 위치와 시설 위치·크기를 맞추고 없는 자리는 추가한다. 예약·배정·장박·사용중지·이력·자리 ID·객실 유형·이름·삭제 상태·추가 자리·항공사진은 유지한다. 삭제한 자리를 임의로 복구하지 않는다. 중복된 자리·시설이나 다른 동으로 이동한 공식 자리와 충돌하면 일부만 적용하지 않고 오류로 멈춘다.

적용 후 운영자가 다시 편집한 위치는 재실행·업데이트에서도 유지한다. 기존 **소풍캠핑장 도면 적용**은 종이 도면의 빠진 항목을 채우는 이전 기능이며, 이번 저장된 편집 배치를 기존 PC에 맞추려면 설정의 새 메뉴를 사용한다.
